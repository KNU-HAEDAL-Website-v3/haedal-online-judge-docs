# 3. 권한 모델 - 전역 2단 + 분반 2단

- 날짜: 2026-08-14 · 상태: 확정 · 상세: [../permissions.md](../permissions.md)

## 결정

- `User.global_role`(ADMIN/MEMBER) + `Enrollment.role`(OPERATOR/STUDENT)의 2층 구조
- 판정: 공통 컴포넌트 4단계

## 기각한 대안

1. **임원 + 교육운영진을 하나의 슈퍼유저로 통합**
   - 남의 반 조작 가능, 학기 종료 후 권한 잔존, 매 학기 명단 정리 필요 → 최소권한 위반
2. **전역 3단 등급(ADMIN/OPERATOR/MEMBER)**
   - "어느 반의 운영자인가"를 저장할 테이블이 결국 필요 → 범위 모델로 회귀
   - 처음부터 2층 구조 채택
