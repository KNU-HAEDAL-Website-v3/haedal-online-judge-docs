# 0001. 백엔드 프레임워크로 Spring Boot 채택

- 날짜: 2026-08-02
- 상태: 승인

## 배경

조직 공통 가이드는 "쉬운 프레임워크(파이썬 등)" 사용을 권장한다. 그러나 본 프로젝트 백엔드 담당의 주력 스택과 팀 상황을 고려해 Spring Boot 채택을 제안한다.

## 선택지

| 선택지 | 장점 | 단점 |
|--------|------|------|
| FastAPI (조직 권장) | 조직 가이드 부합, 진입장벽 낮음 | 현 백엔드 담당의 실무 숙련도 대비 학습 전환 비용 |
| Spring Boot (제안) | 담당자 생산성, 타입 안정성, 국내 취업 시장 표준 스택 경험 | 조직 가이드와 다름, 신규 기여자 진입장벽 |

## 결정

spring boot 채택

## 이유

1. 백엔드 담당의 주력 스택
2. 과제 제출, 채점 서비스 및 OJ 서비스 구현으로 프로젝트 규모가 커질 가능성이 존재함. => 프로젝트를 구조화하여 구현
