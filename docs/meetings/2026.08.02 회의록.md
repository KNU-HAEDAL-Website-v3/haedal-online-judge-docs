# 2026.08.02 회의록

## 논의 내용

### 1. 교육운영 경험 공유 — 요구사항 수집

- 부트캠프생 관리(제출 수합, 현황 파악)에 손이 많이 간다는 문제 공유
- C 트랙: 과제를 백준으로 진행했었음 → 코드 자동채점 수요 확인. 단 백준이라는 대체 수단이 있어 자동채점(P2)이 늦어져도 학기 운영은 가능
- 웹 트랙: 피그마 → HTML → CSS → JS 순서로 소개페이지를 만드는 커리큘럼 → 자동채점 불가. 파일 제출 + 멘토 리뷰 경로가 필수
- 심화반은 파일 제출 중심
- 출석부 필요성 언급 (플랫폼 포함 여부는 미결)

### 2. MVP 범위

- 코드 제출 기능
- 사용자용 / 관리자용 대시보드 2종
- 접근 제어: 자기가 속한 기수의 내용만 보이도록

### 3. 기타

- 동아리 홈페이지의 회원 정보를 과제 관리에 활용하는 방향에 공감 (세부 방식 추후)
- 플랫폼 위에서 대회 개최에 긍정적 — 현 단계 스코프에는 미포함 유지

## 결정 사항

| 결정 | 이유 |
|------|------|
| 제출 방식은 과제별로 다르게 지원 (코드 / 파일) | 웹·심화 과제는 자동채점 불가. 실제 운영에서도 트랙별 제출 형태가 달랐음 |
| 대시보드는 사용자·관리자 2종, 소속 기수 기준으로만 노출 | 운영진은 현황 파악, 학생은 자기 것만 — 혼란과 불필요한 노출 방지 |
| 홈페이지 회원 정보를 가입·명부 관리에 활용 | 동아리원 명부 이중 관리 방지. 연동 방식은 추후 확정 |
| 작업 레포: `KNU-HAEDAL-Website-v3/haedal-online-judge` 생성 | 조직 산하 public 모노레포로 통합 관리 |
| 프론트엔드는 PM이 임시 겸임 | 담당자 불참으로 인한 지연 방지. 착수는 Figma 확정 후 |
