# Haedal Online Judge (HOJ)

해달 부트캠프 과제 제출·관리 플랫폼입니다. 자동 채점과 온라인 저지까지 한 곳에서 제공합니다.

> 🚧 현재 개발 중입니다. (2026 여름방학 ~ )

## 무엇을 하는 프로젝트인가요?

부트캠프 운영에서 반복되는 일 (과제 수합, 마감 관리, 제출 현황 파악, 채점) 을 한 곳에서 처리합니다.

- **학생**: 과제를 확인하고, 코드·파일을 제출하고, 결과를 확인합니다.
- **운영진**: 기수·과제를 등록하고, 누가 냈고 안 냈는지 한눈에 봅니다.
- **모두**: 백준처럼 상시 문제를 풀 수 있는 온라인 저지(OJ)를 사용합니다.

## 개발 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| P1 | 로그인, 기수/과제 관리, 제출, 현황 대시보드 | 🔨 진행 중 |
| P2 | 자동 채점 (Judge0) | ⏳ 예정 |
| P3 | 온라인 저지 모드 (상시 문제 풀 + 리더보드) | ⏳ 예정 |
